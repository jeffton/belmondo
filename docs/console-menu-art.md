# BELMONDO console graphics

The OpenAI Image six-screen study sets the menu language: cream paper and off-black, cut at motorsport angles, with a single vermilion selection. The paddock, speed and craft sit to the left of the live course; wide course-select and pause turn the composition around. Portrait uses the same cut across the bottom, leaving the world visible above. Pause retains the live 3D frame; result cards sit over the continuing race. Plain-text controls stay live. The study is not a UI texture or a source of new rules.

`public/art/belmondo-wordmark.svg` is a vector trace of the BELMONDO wordmark from the study. Belmondo Sprint is the menu alias for an ASCII-only WOFF2 instance of the existing SIL OFL Archivo italic (900 weight, 125 width); see `public/fonts/archivo-OFL.txt`. The race HUD keeps its own type. Existing team emblems and craft models remain the visual identity of each entry.

Back and Select/Start have the same hit boxes on all setup pages. Use a single selection highlight; avoid decorative counters and chrome that reduces the live window. Test portrait and short landscape with safe-area insets, along with the keyboard and standard gamepad paths.
