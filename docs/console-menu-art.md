# BELMONDO console graphics

The OpenAI Image six-screen study sets the menu language: cream paper and off-black ink, cut at motorsport angles, with a single vermilion selection. The paddock, speed and craft sit to the left of the live course; wide course-select and pause turn the composition around. Portrait uses the same cut across the bottom, leaving the world visible above. Pause retains the live 3D frame; result cards sit over the continuing race. Plain-text controls stay live. The study is not a UI texture or a source of new rules.

`public/art/belmondo-wordmark.svg` is a vector trace of the BELMONDO wordmark from the study. Belmondo Sprint is the menu alias for an ASCII-only WOFF2 instance of the existing SIL OFL Archivo italic (900 weight, 125 width); see `public/fonts/archivo-OFL.txt`. The race HUD uses the same display face for position, lap, speed and status, with tabular telemetry for timing. Existing team emblems and craft models remain the visual identity of each entry.

The OpenAI Image race interface study carries those angled cream timing plates over a running course, with a dark weapon badge and red reserved for critical or active states. The sampled board is a composition guide, not an asset: flight and airbrake stay analogue, touch targets keep uncut hit areas, and touch shows the equipped glyph on FIRE rather than adding a second inventory.

Back and Select/Start have the same hit boxes on all setup pages. Use a single selection highlight; avoid decorative counters and chrome that reduces the live window. Test portrait and short landscape with safe-area insets, along with the keyboard and standard gamepad paths.
