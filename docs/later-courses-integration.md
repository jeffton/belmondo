# Later-course CPU integration

This candidate combines legacy-v4 routes and grounded worlds, Whiteout-2's original spiral/base with distinct forks, Cinderline-2's technical valley and ballistic crest, Monsoon-4's conduit/reservoir forks, Vesper, biome vegetation, physical NPC steering, Coast/Solar fork environments and countdown voice.

## Acceptance

Completed CPU batches cover 683 distinct test cases, including the 108-run legacy terrain matrix, 72 single-NPC craft/class/fork cases, both Cinderline eight-ship five-lap packs, Vesper's terrain-aware routing, emitted architecture, fork seams, terrain sweeps, pickups and all ordinary expansion-course shield gates. Heavy matrices run by course/name filter within the 60-second job deadline. Build and formatting pass. Private soundtrack masters are staged from the external audio archive, not committed.

Configuration and sampled-output fixtures describe the intentionally integrated layouts. Monsoon's steep crest, original deck/outlet, full-width clearance and pickup-targeted fairness contracts remain enforced. Whiteout's original base points and spiral remain exact.

Monsoon's natural NPC line does not collect the optional upper-route boost seven metres off centre: the upper approach costs 1.15 seconds in C1 and 0.825 seconds in C3. Both ordinary paths complete with 100 shield and no rail contacts/rescues. Fairness uses independent reward-targeting control with both rewards physically collected; its original 0.5/pace-second budget is unchanged.

Vesper has elevated urban roofs above a flat city floor, not terrain-following countryside. Its generic terrain checks retain deck-clearance, emitted-surface rays and sweeps; the architecture suite checks rooftop clearances. Its explicit empty vegetation profile allocates no plant meshes.

GPU, visual/native-input acceptance and deployment are separate gates. This CPU integration does not modify the frozen release overlay or root working tree.
